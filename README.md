# Crown & Country

*A medieval kingdom management simulator built with Python and Pygame.*

## 📖 About

Crown & Country is an independently developed kingdom management and strategy game, currently in the earliest stages of development.

The project aims to create an immersive, primarily text-based strategy experience with a minimalist graphical interface. Players will eventually be able to govern kingdoms, manage economies, command armies, establish diplomatic relations and navigate historical challenges.

This is my first major programming passion project, developed primarily as an educational experience to improve my understanding of Python, software development and game design.

Development is AI-assisted, with an emphasis on independently writing code, understanding programming concepts and learning professional development practices.

## 🎮 Current Features

As of version **0.0.1**, the project includes:

- A functional 1280 × 720 Pygame window.
- Custom application title and background.
- A game loop with a 60 FPS limit.
- Basic event handling and clean application shutdown.

The game is not yet playable.

## 🏰 Planned Features

The long-term vision for Crown & Country includes:

### Kingdom Management
- Manage population, resources and infrastructure.
- Develop settlements and expand territories.
- Establish laws and government policies.
- Maintain stability and public satisfaction.

### Economy
- Implement taxation and government spending.
- Develop agriculture, trade and industry.
- Manage resources, production and consumption.
- Respond to economic crises.

### Diplomacy and Warfare
- Establish relationships with neighbouring kingdoms.
- Negotiate alliances and trade agreements.
- Recruit, organise and command armies.
- Engage in warfare and territorial expansion.

### History and Politics
- Experience events inspired by real historical dilemmas.
- Navigate political instability and succession crises.
- Explore different historical periods.
- Shape an alternative historical timeline through player decisions.

*These features represent development goals and are subject to change.*

## 💻 Installation

### Requirements
- Python 3
- Pygame

### Running the Project

1. Clone or download the repository.
2. Install Pygame using:

   ```bash
   python -m pip install pygame
   ```

3. Navigate to the project directory.
4. Launch the application using:

   ```bash
   python main.py
   ```

Installation instructions may change as the project develops.
